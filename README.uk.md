# Perfect World Offline Server

[English](README.md) | **Українська** | [Русский](README.ru.md)

Грайте в Perfect World 1.7.6, найновішу версію, яка є в спільноти, офлайн на своєму комп'ютері. Сервер працює в Docker, клієнт на тій самій машині, а виправлення, без яких цей сервер узагалі не стартує, вже застосовані.

| | Статус |
|---|---|
| macOS на Apple Silicon (M1-M4) | Перевірено. Сервер через Rosetta, клієнт через CrossOver |
| Windows (x64) | Поки не перевірено. Має працювати з Docker Desktop і рідним клієнтом |
| Linux (x64) | Поки не перевірено. Серверна частина та сама, клієнт через Wine |
| Російський клієнт (1.7.6 збірка 4311) | Перевірено |
| Англійський клієнт | Поки не підтримується, див. [Мова](#мова) |

У репозиторії лише скрипти, конфігурація й документація. Файлів гри тут немає, сервер і клієнт ви завантажуєте самі.

## Як це влаштовано

```
ваш комп'ютер
├── Docker-контейнер "pw-server" (Debian 12, x86-64)
│   ├── MariaDB (акаунти, ліцензія)
│   └── 10 демонів PW + ігровий світ, слухають 127.0.0.1:29000
└── клієнт PW (Windows-застосунок, рідний або в CrossOver/Wine)
```

Усі дані гри (файли сервера, база, клієнт) лежать у папці `game/` цього репозиторію. Git її ігнорує.

## Вимоги

- 16 ГБ ОЗП. Ігровий світ займає близько 3 ГБ, клієнт ще 2-3 ГБ.
- Близько 75 ГБ вільного місця: 30 ГБ завантажень, 35 ГБ після розпакування, плюс база.
- 7-Zip. На macOS `brew install sevenzip`, на Windows з [7-zip.org](https://www.7-zip.org/).
- Docker. На macOS [OrbStack](https://orbstack.dev/) (на ньому я перевіряв) або Docker Desktop з увімкненою Rosetta. На Windows [Docker Desktop](https://www.docker.com/products/docker-desktop/) з WSL 2.
- На macOS ще [CrossOver](https://www.codeweavers.com/crossover), щоб запускати Windows-клієнт.

## 1. Завантажте файли гри

Завантажте ці файли й покладіть у папку `game/` (створіть її поруч із цим README):

| Файл | Розмір | Що це |
|---|---|---|
| `PWServer176.7z` | 2,2 ГБ | Сервер 1.7.6 збірка 4311 з дампами SQL і скриптами керування |
| `PerfectWorld-176.7z` | 25,5 ГБ | Російський клієнт 1.7.6 збірка 4311, уже пропатчений під цей сервер |
| `Patch-client-1.7.6-ru.7z` | 22 МБ | Необов'язково. Потрібен, лише якщо у вас інший, непропатчений клієнт 1.7.6 збірки 4311 |

Сервер і патч лежать на Google Drive, посилання на них є в мануалі автора роздачі «Установка PW v1.7.6 Build 4311 сервера, IWEB, PWAdmin». Сайт, де він був, уже не працює, але в [копії у Web Archive](https://web.archive.org/web/20260512052954/https://www.habrhub.ru/Servers/PerfectWorld/PW-v176+IWEB+PWAdmin/pw-v176+iweb+pwadmin) посилання збереглися.

Клієнт береться з роздачі на RuTracker «Perfect World + Server v1.7.6 Build 4311 [amd64] [RUS] [Wine]». У торрент-клієнті позначте лише `PerfectWorld-176.7z`. Другий файл роздачі, `PWSERVER-1.7.6.7z`, це образ VirtualBox того самого сервера, він вам не потрібен.

Більше подробиць і дзеркала є в темі «1.7.6 server + client» на RaGEZONE, розділ Perfect World Releases.

Має вийти так:

```
perfect-world-offline-server/
└── game/
    ├── PWServer176.7z
    └── PerfectWorld-176.7z
```

## 2. Встановіть сервер і клієнт

### macOS

```bash
scripts/macos/setup.sh                     # розпаковує все в game/ (займає час)
docker compose up -d --build               # перший запуск імпортує базу, близько хвилини
scripts/macos/create-account.sh admin admin
```

Потім налаштуйте CrossOver:

1. **Bottle → New Bottle**, назва `Perfect World`, тип **Windows 10 64-bit**.
2. У цій бутилці через **Install Software** встановіть:
   - **Microsoft DirectX for Modern Games**
   - **Microsoft Visual C++ 2005 SP1, 2008, 2010 Redistributable**, 32-бітні версії, без «(64-bit)»
   - **Nvidia PhysX Legacy (2012)**, необов'язково
3. Застосуйте до бутилки виправлення іконок:

   ```bash
   scripts/macos/crossover-bottle.sh "Perfect World"
   ```

### Windows (поки не перевірено)

У PowerShell з папки репозиторію:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\windows\setup.ps1
docker compose up -d --build
powershell -ExecutionPolicy Bypass -File scripts\windows\create-account.ps1 admin admin
```

Якщо клієнт скаржиться на відсутні бібліотеки, встановіть [DirectX End-User Runtime (June 2010)](https://www.microsoft.com/download/details.aspx?id=8109) і 32-бітні Visual C++ 2005/2008/2010 Redistributable.

### Linux (поки не перевірено)

Сервер запускається так само, як на macOS (`docker compose up -d --build`). Скрипт створення акаунта працює без змін. Клієнт у роздачі зібраний під Wine і сам містить лаунчер (`start.sh`). Пропишіть `127.0.0.1` у `serverlist.txt`, як це робить `setup.sh`.

## 3. Грайте

Запускайте 32-бітний клієнт з аргументами:

```
game\element\elementclient.exe game:cpw nocheck startbypatcher console:1
```

Повний шлях: `game/client/PerfectWorld-176/game_info/data/element/elementclient.exe`.

На macOS відкрийте в CrossOver бутилку `Perfect World`, натисніть Run Command, виберіть файл, допишіть аргументи й позначте «Save command as a launcher», щоб не робити це щоразу. На Windows створіть ярлик на `elementclient.exe` і допишіть аргументи в кінець поля «Об'єкт».

Входьте під створеним акаунтом, наприклад `admin` / `admin`. Сервер у списку називається ServerPW, акаунт має права GM.

64-бітний клієнт (`element\x64\elementclient_64.exe`) у CrossOver не запускається. На Windows може й запуститися, я не перевіряв.

## Щоденне використання

| Дія | Команда |
|---|---|
| Запустити сервер | `docker compose up -d` (готовий приблизно за хвилину) |
| Зупинити сервер | `docker compose stop` (триває до двох хвилин) |
| Логи сервера | `docker logs -f pw-server` |
| Стан усіх демонів | `docker exec pw-server /root/server status` |
| Створити ще акаунт | `scripts/macos/create-account.sh <логін> <пароль>` |

Завжди зупиняйте сервер через `docker compose stop` або кнопкою Stop в OrbStack / Docker Desktop. Контейнер відключає клієнтів, чекає, поки ігрова база запишеться на диск, і лише потім вимикає гру й MariaDB. Це триває від 30 секунд до двох хвилин, не переривайте зупинку. Для надійності вийдіть із гри перед зупинкою сервера. Не вбивайте Docker і не від'єднуйте диск, поки сервер працює.

За замовчуванням для економії пам'яті запускаються лише основний світ (`gs01`) і один інстанс (`is61`). Інші карти: `docker exec pw-server /root/server start-map <id карти>`, список id у `game/server/root/pwserver/maps`.

## Що виправлено

«З коробки» цей сервер або не стартує, або стартує і ламається вже в клієнті. Ось чому, і все це обробляють контейнер і скрипти:

| Проблема | Симптом | Виправлення |
|---|---|---|
| Ліцензія до 2090 року, а `UNIX_TIMESTAMP()` у MariaDB 10.11 працює лише до 2038 | `licenseservice.log`: *license time out*, усі демони вимикаються, «сервер зупиняється на 30%» | `entrypoint.sh` при кожному старті ставить дату 2037-12-31 |
| Демони при старті надсилають `SIGUSR1` батьківському процесу | Скрипт керування помирає після першого демона, решта не запускаються | Скрипт керування працює всередині bash, який перехоплює `USR1` |
| `docker stop` вбивав MariaDB без коректного вимкнення | Код виходу контейнера 137, ризик пошкодити базу | Перехоплення `SIGTERM`: спершу `server stop`, потім `mariadb-admin shutdown` |
| `server stop` вбиває всі демони через `kill -9` | Після перезапуску останні 5-10 хвилин гри відкочуються | Перед `server stop` entrypoint зупиняє `glinkd` і чекає на checkpoint `gamedbd` |
| `serverlist.txt` вказує на IP VirtualBox автора `192.168.0.195` | Клієнт не знаходить сервер | Перезаписується з `127.0.0.1`, зі збереженням UTF-16 LE і BOM |
| В архівах гри китайські (GBK) назви файлів | У CrossOver/Wine: `?` замість іконок предметів і вмінь, немає частини ефектів | Бутилка запускається з `LANG=zh_CN.UTF-8`, текст гри лишається російським |
| Бінарники сервера під x86-64 | На Apple Silicon напряму не запускаються | `platform: linux/amd64`, їх запускає Rosetta |

## Розв'язання проблем

**Клієнт пише, що версія неправильна.** Сервер і клієнт мають бути однієї збірки (4311) з однаковими `elements.data` і `tasks.data`. Використовуйте клієнт з роздачі вище або застосуйте `Patch-client-1.7.6-ru.7z`.

**`?` замість іконок (macOS).** Запустіть `scripts/macos/crossover-bottle.sh`, потім повністю закрийте CrossOver і запустіть гру знову.

**Сервер не запускається.** Дивіться `docker logs pw-server` і `game/server/root/pwserver/logs/licenseservice.log`. Якщо там *license time out*, виправлення дати ліцензії не застосувалося, перевірте, що база `licenseservice` існує.

**Почати з нуля.** `docker compose down`, потім видаліть `game/mysql`. Під час наступного запуску база імпортується заново. Усі персонажі буде втрачено.

## Мова

Підтримується лише російський клієнт. Файли сервера, `elements.data` (предмети, NPC) і `tasks.data` (квести) взято з російської версії 1.7.6 збірки 4311. В англійського клієнта (PWI 1.7.6 збірка 4727-pwi-1292) інші дані й інша версія клієнта: на RaGEZONE користувачі повідомляють про помилку версії під час входу саме на цей сервер.

Для англійської версії потрібна англійська збірка сервера 1.7.6 з відповідними даними. Якщо у вас є робоча англійська пара «сервер + клієнт», надсилайте, Docker-частина й усі виправлення лишаться тими самими.
