# Perfect World Offline Server

[English](README.md) | [Українська](README.uk.md) | **Русский**

Играйте в Perfect World 1.7.6, самую новую версию, которая есть у сообщества, офлайн на своём компьютере. Сервер работает в Docker, клиент на той же машине, а исправления, без которых этот сервер вообще не стартует, уже применены.

| | Статус |
|---|---|
| macOS на Apple Silicon (M1-M4) | Проверено. Сервер через Rosetta, клиент через CrossOver |
| Windows (x64) | Пока не проверено. Должно работать с Docker Desktop и родным клиентом |
| Linux (x64) | Пока не проверено. Серверная часть та же, клиент через Wine |
| Русский клиент (1.7.6 сборка 4311) | Проверено |
| Английский клиент | Пока не поддерживается, см. [Язык](#язык) |

В репозитории только скрипты, конфигурация и документация. Файлов игры здесь нет, сервер и клиент вы скачиваете сами.

## Как это устроено

```
ваш компьютер
├── Docker-контейнер "pw-server" (Debian 12, x86-64)
│   ├── MariaDB (аккаунты, лицензия)
│   └── 10 демонов PW + игровой мир, слушают 127.0.0.1:29000
└── клиент PW (Windows-приложение, родное или в CrossOver/Wine)
```

Все данные игры (файлы сервера, база, клиент) лежат в папке `game/` этого репозитория. Git её игнорирует.

## Требования

- 16 ГБ ОЗУ. Игровой мир занимает около 3 ГБ, клиент ещё 2-3 ГБ.
- Около 75 ГБ свободного места: 30 ГБ загрузок, 35 ГБ после распаковки, плюс база.
- 7-Zip. На macOS `brew install sevenzip`, на Windows с [7-zip.org](https://www.7-zip.org/).
- Docker. На macOS [OrbStack](https://orbstack.dev/) (на нём я проверял) или Docker Desktop с включённой Rosetta. На Windows [Docker Desktop](https://www.docker.com/products/docker-desktop/) с WSL 2.
- На macOS ещё [CrossOver](https://www.codeweavers.com/crossover), чтобы запускать Windows-клиент.

## 1. Скачайте файлы игры

Скачайте эти файлы и положите в папку `game/` (создайте её рядом с этим README):

| Файл | Размер | Что это |
|---|---|---|
| `PWServer176.7z` | 2,2 ГБ | Сервер 1.7.6 сборка 4311 с дампами SQL и скриптами управления |
| `PerfectWorld-176.7z` | 25,5 ГБ | Русский клиент 1.7.6 сборка 4311, уже пропатчен под этот сервер |
| `Patch-client-1.7.6-ru.7z` | 22 МБ | Необязательно. Нужен, только если у вас другой, непропатченный клиент 1.7.6 сборки 4311 |

Сервер и патч лежат на Google Drive, ссылки на них есть в мануале автора раздачи «Установка PW v1.7.6 Build 4311 сервера, IWEB, PWAdmin». Сайт, где он был, уже не работает, но в [копии в Web Archive](https://web.archive.org/web/20260512052954/https://www.habrhub.ru/Servers/PerfectWorld/PW-v176+IWEB+PWAdmin/pw-v176+iweb+pwadmin) ссылки сохранились.

Клиент берётся из раздачи на RuTracker «Perfect World + Server v1.7.6 Build 4311 [amd64] [RUS] [Wine]». В торрент-клиенте отметьте только `PerfectWorld-176.7z`. Второй файл раздачи, `PWSERVER-1.7.6.7z`, это образ VirtualBox того же сервера, он вам не нужен.

Больше подробностей и зеркала есть в теме «1.7.6 server + client» на RaGEZONE, раздел Perfect World Releases.

Должно получиться так:

```
perfect-world-offline-server/
└── game/
    ├── PWServer176.7z
    └── PerfectWorld-176.7z
```

## 2. Установите сервер и клиент

### macOS

```bash
scripts/macos/setup.sh                     # распаковывает всё в game/ (занимает время)
docker compose up -d --build               # первый запуск импортирует базу, около минуты
scripts/macos/create-account.sh admin admin
```

Затем настройте CrossOver:

1. **Bottle → New Bottle**, название `Perfect World`, тип **Windows 10 64-bit**.
2. В этой бутылке через **Install Software** установите:
   - **Microsoft DirectX for Modern Games**
   - **Microsoft Visual C++ 2005 SP1, 2008, 2010 Redistributable**, 32-битные версии, без «(64-bit)»
   - **Nvidia PhysX Legacy (2012)**, необязательно
3. Примените к бутылке исправление иконок:

   ```bash
   scripts/macos/crossover-bottle.sh "Perfect World"
   ```

### Windows (пока не проверено)

В PowerShell из папки репозитория:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\windows\setup.ps1
docker compose up -d --build
powershell -ExecutionPolicy Bypass -File scripts\windows\create-account.ps1 admin admin
```

Если клиент жалуется на отсутствующие библиотеки, установите [DirectX End-User Runtime (June 2010)](https://www.microsoft.com/download/details.aspx?id=8109) и 32-битные Visual C++ 2005/2008/2010 Redistributable.

### Linux (пока не проверено)

Сервер запускается так же, как на macOS (`docker compose up -d --build`). Скрипт создания аккаунта работает без изменений. Клиент в раздаче собран под Wine и сам содержит лаунчер (`start.sh`). Пропишите `127.0.0.1` в `serverlist.txt`, как это делает `setup.sh`.

## 3. Играйте

Запускайте 32-битный клиент с аргументами:

```
game\element\elementclient.exe game:cpw nocheck startbypatcher console:1
```

Полный путь: `game/client/PerfectWorld-176/game_info/data/element/elementclient.exe`.

На macOS откройте в CrossOver бутылку `Perfect World`, нажмите Run Command, выберите файл, допишите аргументы и отметьте «Save command as a launcher», чтобы не делать это каждый раз. На Windows создайте ярлык на `elementclient.exe` и допишите аргументы в конец поля «Объект».

Входите под созданным аккаунтом, например `admin` / `admin`. Сервер в списке называется ServerPW, у аккаунта права GM.

64-битный клиент (`element\x64\elementclient_64.exe`) в CrossOver не запускается. На Windows может и запуститься, я не проверял.

## Повседневное использование

| Действие | Команда |
|---|---|
| Запустить сервер | `docker compose up -d` (готов примерно через минуту) |
| Остановить сервер | `docker compose stop` (занимает до двух минут) |
| Логи сервера | `docker logs -f pw-server` |
| Состояние всех демонов | `docker exec pw-server /root/server status` |
| Создать ещё аккаунт | `scripts/macos/create-account.sh <логин> <пароль>` |

Всегда останавливайте сервер через `docker compose stop` или кнопкой Stop в OrbStack / Docker Desktop. Контейнер отключает клиентов, ждёт, пока игровая база запишется на диск, и только потом выключает игру и MariaDB. Это занимает от 30 секунд до двух минут, не прерывайте остановку. Для надёжности выйдите из игры перед остановкой сервера. Не убивайте Docker и не отключайте диск, пока сервер работает.

По умолчанию для экономии памяти запускаются только основной мир (`gs01`) и один инстанс (`is61`). Другие карты: `docker exec pw-server /root/server start-map <id карты>`, список id в `game/server/root/pwserver/maps`.

## Что исправлено

«Из коробки» этот сервер либо не стартует, либо стартует и ломается уже в клиенте. Вот почему, и всё это обрабатывают контейнер и скрипты:

| Проблема | Симптом | Исправление |
|---|---|---|
| Лицензия до 2090 года, а `UNIX_TIMESTAMP()` в MariaDB 10.11 работает только до 2038 | `licenseservice.log`: *license time out*, все демоны выключаются, «сервер останавливается на 30%» | `entrypoint.sh` при каждом старте ставит дату 2037-12-31 |
| Демоны при старте шлют `SIGUSR1` родительскому процессу | Скрипт управления умирает после первого демона, остальные не запускаются | Скрипт управления работает внутри bash, который перехватывает `USR1` |
| `docker stop` убивал MariaDB без корректного выключения | Код выхода контейнера 137, риск повредить базу | Перехват `SIGTERM`: сначала `server stop`, затем `mariadb-admin shutdown` |
| `server stop` убивает все демоны через `kill -9` | После перезапуска последние 5-10 минут игры откатываются | Перед `server stop` entrypoint останавливает `glinkd` и ждёт checkpoint `gamedbd` |
| `serverlist.txt` указывает на IP VirtualBox автора `192.168.0.195` | Клиент не находит сервер | Перезаписывается с `127.0.0.1`, с сохранением UTF-16 LE и BOM |
| В архивах игры китайские (GBK) имена файлов | В CrossOver/Wine: `?` вместо иконок предметов и умений, нет части эффектов | Бутылка запускается с `LANG=zh_CN.UTF-8`, текст игры остаётся русским |
| Бинарники сервера под x86-64 | На Apple Silicon напрямую не запускаются | `platform: linux/amd64`, их запускает Rosetta |

## Решение проблем

**Клиент пишет, что версия неверная.** Сервер и клиент должны быть одной сборки (4311) с одинаковыми `elements.data` и `tasks.data`. Используйте клиент из раздачи выше или примените `Patch-client-1.7.6-ru.7z`.

**`?` вместо иконок (macOS).** Запустите `scripts/macos/crossover-bottle.sh`, затем полностью закройте CrossOver и запустите игру снова.

**Сервер не запускается.** Смотрите `docker logs pw-server` и `game/server/root/pwserver/logs/licenseservice.log`. Если там *license time out*, исправление даты лицензии не применилось, проверьте, что база `licenseservice` существует.

**Начать с нуля.** `docker compose down`, затем удалите `game/mysql`. При следующем запуске база импортируется заново. Все персонажи будут потеряны.

## Язык

Поддерживается только русский клиент. Файлы сервера, `elements.data` (предметы, NPC) и `tasks.data` (квесты) взяты из русской версии 1.7.6 сборки 4311. У английского клиента (PWI 1.7.6 сборка 4727-pwi-1292) другие данные и другая версия клиента: на RaGEZONE пользователи сообщают об ошибке версии при входе именно на этот сервер.

Для английской версии нужна английская сборка сервера 1.7.6 с совпадающими данными. Если у вас есть рабочая английская пара «сервер + клиент», присылайте, Docker-часть и все исправления останутся теми же.
